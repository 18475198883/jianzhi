# 减脂管家 — 使用说明书

手机端 AI 减脂助手。聊天式记录饮食/运动/体重，AI 智能分析，数据图表可视化，朋友圈分享成果。

---

## 一、准备工作（5 分钟，只做一次）

### 1.1 申请 DeepSeek API Key

这是 AI 聊天功能的"钥匙"，需要你自己申请：

1. 打开 https://platform.deepseek.com
2. 用手机号或微信注册登录
3. 点击「API Keys」→「创建 API Key」，复制保存（格式：`sk-...`）

**费用说明：** DeepSeek 的 API 非常便宜，正常使用一个月大约 2-5 元。余额用完需自行充值。

### 1.2 打开应用

有两种方式：

**方式 A（推荐）：部署到 Gitee Pages**

参照第五节部署后，用手机浏览器打开网址即可，像访问普通网站一样。

**方式 B：离线使用**

把整个 `src/` 文件夹打包成 ZIP 发送到手机，解压后用浏览器打开 `chat.html`。

## 二、首次设置（1 分钟）

首次打开应用，会自动弹出设置窗口：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| API Key | 粘贴你申请的 DeepSeek Key | `sk-abc123...` |
| 性别 | 男/女 | 男 |
| 年龄 | 你的年龄 | 30 |
| 身高 | 单位 cm | 165 |
| 当前体重 | 单位 kg | 70 |
| 目标体重 | 你想减到多少 | 55 |

设置完成后，系统自动算出你每天该吃多少热量，并在聊天框显示欢迎语。

> **测试 API Key 是否可用：** 填入 Key 后点击「测试连接」，显示 ✅ 即为正常。

## 三、日常使用（核心功能）

### 3.1 聊天记录——主界面

聊天页是你每天使用的核心入口。**像跟朋友聊天一样发消息**，AI 会自动理解并记录。

#### 记录饮食

直接打字告诉 AI 你今天吃了什么：

```
早餐：一个水煮蛋，一杯豆浆，一个小馒头
午餐：外卖黄焖鸡米饭，小份
晚餐：麻辣烫，清汤锅底，多拿了蔬菜
```

AI 会自动估算每餐的热量和营养，回复你今日剩余预算。

#### 快捷模板

点击底部工具栏的「⚡快捷」，弹出常用模板：

- 🍳 早餐 / 🍱 午餐 / 🍲 晚餐 / 🍎 加餐 — 快速选餐
- ⚖️ 报体重 — 今早空腹体重记录
- 🏃 跑步 / 🚶 快走 / 💪 家庭HIIT — 运动记录
- 🔄 跟昨天一样 — 重复昨天饮食
- 😴 休息日 — 今日没运动

#### 拍照识别

点击「📷拍照」，拍你的食物或体脂秤/运动 App 截图，AI 会提取数据自动记录。

#### 语音输入

点击「🎤语音」，直接说今天吃了什么 / 做了多少运动。

### 3.2 问 AI 问题

除了记录，你还可以问任何减脂相关的问题：

- "麻辣烫怎么吃最不胖？"
- "今天只吃了 1200 千卡，运动了 40 分钟，够不够？"
- "最近三天体重没变了，怎么回事？"
- "周末要聚餐，给个建议"
- "我有点不想动了怎么办..."

### 3.3 顶部信息卡

聊天页顶部实时显示：

- **今日剩余** — 还能吃多少千卡（颜色会随剩余量变化）
- **阶段** — 当前处于哪个减脂阶段（适应期→减脂期→巩固期等）
- **进度** — 还差多少公斤，已坚持多少天

## 四、数据仪表盘

点击聊天页右上角「📊看板」，或直接打开 `dashboard.html`。

### 4.1 四个统计卡片

| 卡片 | 含义 |
|------|------|
| 本周运动 | 这周运动了几次 |
| 日均摄入 | 最近 7 天平均每天吃了多少 |
| 连续运动 | 当前连续运动天数 |
| 累计减重 | 从开始到现在瘦了多少 |

### 4.2 三张图表

- **体重趋势图**（折线图）— 体重曲线 + 目标线，直观看减重轨迹
- **热量对比图**（柱状图）— 近 14 天橙色=摄入，绿色=运动消耗
- **运动日历**（热力图）— 近 90 天，有运动的日期显示绿色方块

### 4.3 隐私模式

点击「🔒隐私」按钮可以隐藏所有数字，只显示趋势。适合给别人看仪表盘截图时保护隐私。

点击隐私模态中的齿轮可以自定义哪些信息隐藏/显示，以及添加水印文字。

## 六、部署到 Gitee Pages（推荐）

部署后，所有朋友都可以通过链接访问（每个人各自用自己的 API Key，数据互不干扰）。

### 6.1 首次部署

1. 注册 Gitee 账号：https://gitee.com
2. 创建新仓库（名称随意，建议英文如 `jianzhi`）
3. 在电脑上把 `src/` 目录下所有文件推送到仓库：

```bash
cd src/
git init
git add .
git commit -m "减脂管家首次发布"
git remote add origin https://gitee.com/你的用户名/仓库名.git
git push -u origin master
```

4. 在 Gitee 仓库页面：**服务 → Gitee Pages**
5. 部署目录选择 `/`（根目录），点击「启动」
6. 等待 1-2 分钟，获得网址：`https://你的用户名.gitee.io/仓库名/chat.html`
7. 把网址添加到手机浏览器主页或书签

### 6.2 后续更新

当通过 Claude 改进了功能，更新部署：

```bash
cd src/
git add . && git commit -m "功能更新"
git push origin master
# Gitee Pages 会自动重新部署，约 1-2 分钟生效
```

手机端刷新页面即可看到新版本。

## 七、数据管理

### 7.1 数据存储位置

所有数据存储在**手机浏览器本地**（localStorage），不上传到任何服务器。每台设备数据完全隔离。

### 7.2 数据备份（建议每周一次）

在聊天页底部点击「反馈 / 功能升级」旁的隐藏区域，或通过设置面板：

- **导出：** 仪表盘页面点击「导出数据」，保存 JSON 文件到手机
- **导入：** 设置面板点击「从备份恢复数据」，选择之前导出的 JSON 文件

### 7.3 隐私保护

- API Key 只在本地存储，每次请求直接发给 DeepSeek，不经过任何中间服务器
- 朋友使用同一链接时，需要各自输入自己的 API Key
- 隐私模式可以隐藏所有体重/热量数字后再截图分享

## 八、AI 的八大能力

你的减脂管家不只是记录工具，它有八项专业能力：

1. **心理教练** — 不想动时给鼓励，暴食后不责备，体重涨了先安抚
2. **外卖策略** — 你主要吃外卖，AI 会针对麻辣烫、黄焖鸡、快餐等给出具体吃法建议
3. **运动指导** — 针对跑步和家庭自重训练给出动作级指导（跑步时长/心率、HIIT 强度）
4. **睡眠+压力** — 关注熬夜对减脂的影响，给出调整建议
5. **五阶段策略** — 适应期→减脂期→巩固期→冲刺期→维持期，每阶段策略不同
6. **饮食替换库** — 告诉你如何替换不健康的食物（奶茶→无糖茶，炸鸡→烤鸡胸）
7. **个性化记忆** — 记住你的偏好和习惯，回复越来越贴合你
8. **深度分析** — 当你问"为什么不掉称"时，AI 会综合分析饮食、运动、睡眠等所有数据

## 十、常见问题

**Q：换个手机数据还在吗？**

不在。数据存在每台设备的浏览器本地。想换手机请先导出数据，新手机再导入。

**Q：清除浏览器缓存会丢失数据吗？**

会。建议定期导出数据备份。

**Q：API Key 会被别人看到吗？**

不会。Key 存在你手机本地，网页纯静态没有后端服务器。发给 DeepSeek 的请求是直接从你浏览器发出的。

**Q：每天要花多少时间记录？**

正常使用每天 2-5 分钟。快捷模板和拍照功能可进一步缩短时间。

**Q：AI 回复慢怎么办？**

正常 2-5 秒。如果超过 30 秒未回复，检查网络和 API Key 是否有效。

**Q：不想用 AI，能手动记录吗？**

当前版本以 AI 对话为核心。如果想手动记录，可以用快捷模板选餐后不要期待回复。

**Q：能同时两个人用吗？**

可以但不推荐。同一浏览器 localStorage 共享。建议每人用自己手机，或在浏览器开无痕模式使用。
